# 📱 영숙 — 회사 목표, 모든 에이전트의 개인 목표(goal.md), 최근 의사결정 및 메모리 히스토리를 검토하고, 현재 중복되거나 지연되고 있는 작업 목록을 요약하여 business에게 전달합니다.

[분석 대기]

CEO님의 지시를 확인했습니다. 현재 회사 목표, 모든 에이전트의 개인 목표(`goal.md`), 그리고 최근의 의사결정 및 메모리 히스토리를 종합적으로 검토하여, 중복되거나 지연되고 있는 작업을 식별하고 이를 `business` 에이전트에게 전달하는 임무를 수행해야 합니다.

**⚠️ 현재 데이터 부족으로 인해 분석을 시작할 수 없습니다.**

CEO님께서 요청하신 정확한 요약 보고서를 생성하기 위해서는 다음 필수 데이터들이 시스템에 제공되어야 합니다.

1.  **최신 메모리 히스토리:** 최근 24시간~72시간 간의 모든 의사결정, 작업 진행, 병목 현상 관련 로그.
2.  **모든 에이전트의 개인 목표 파일 (`goal.md`):** 각 에이전트가 현재 집중해야 할 목표와 우선순위.
3.  **최신 회사 목표:** 회사가 현재 추구하는 KPI 및 비전.

### 🔎 **[분석 계획 (데이터 확보 시 실행될 프로세스)]**

데이터가 제공되는 즉시, 저는 아래의 3단계 검토 프로세스를 통해 CEO님의 지시를 이행하겠습니다.

**1. 중복 작업 식별 (Redundancy Check):**
*   `Memory` 로그를 분석하여, 동일한 주제나 목표를 가진 작업이 서로 다른 에이전트에게 분배되거나, 단일 작업이 여러 번 반복적으로 논의되고 있는지 확인합니다.
*   (예: "마케팅 전략 A 수립"이 `Writer`와 `Researcher` 모두에게 동시에 할당된 경우.)

**2. 지연 작업 식별 (Delay/Bottleneck Check):**
*   각 에이전트의 `goal.md`와 현재 작업 상태를 비교합니다.
*   가장 높은 가치를 지니지만, 최근 48시간 이상 진전이 없거나, 외부 인프라(PayPal, GitHub 등) 문제로 인해 멈춰있는 작업(Bottleneck)을 식별합니다.

**3. 최적화된 보고서 생성 (Action Briefing):**
*   식별된 중복/지연 작업을 **[문제점]**, **[영향도]**, **[권고 조치]**의 형식으로 구조화합니다.
*   이 구조화된 내용을 `business` 에이전트가 즉시 전략적 의사결정을 내릴 수 있도록 간결하고 실행 가능한 브리프 형태로 요약하여 전달하겠습니다.

**➡️ 데이터가 제공되는 대로 즉시 분석을 재개하겠습니다.**
