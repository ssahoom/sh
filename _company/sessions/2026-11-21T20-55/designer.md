# 🎨 최종 디자인 시스템 및 UI/UX 사양서 (SH MVP)

## 🎯 프로젝트 목표 및 사용자 페르소나
*   **목표:** 극도로 단순하고 직관적인 자동화 도구 MVP 랜딩 페이지 구현.
*   **타깃:** 50대 남성 (높은 실용성, 낮은 디지털 숙련도, 시간 효율 중시).
*   **핵심 원칙:** **간단함(Simplicity)**과 **효율성(Efficiency)**. 복잡한 설명이나 과장된 시각 효과는 절대 배제.

## 🎨 1. 비주얼 아이덴티티 (Visual Identity)
### 1.1. 컬러 팔레트 (Color Palette)
| 용도 | 색상명 | HEX Code | 설명 |
| :--- | :--- | :--- | :--- |
| **Primary (주요 행동)** | Deep Action Blue | `#005A9C` | 신뢰감, 전문성, 행동 유도(CTA)에 사용. (너무 밝거나 화려하지 않도록 지정) |
| **Secondary (보조 강조)** | Accent Teal | `#2ECC71` | 긍정적 피드백, 성공 상태, 강조 포인트에 사용. (신뢰성을 해치지 않는 선에서만 사용) |
| **Background (배경)** | Off-White Gray | `#F5F7F9` | 눈의 피로를 줄이고, 내용에 집중하도록 돕는 차분한 톤. |
| **Text (본문)** | Dark Charcoal | `#333333` | 높은 가독성을 보장하는 진중한 톤. |
| **Error (오류)** | Muted Red | `#CC3333` | 오류 메시지 및 경고에 사용. |

### 1.2. 타이포그래피 (Typography)
*   **폰트:** Pretendard (또는 Noto Sans KR). (한국 사용자에게 가장 높은 가독성을 보장하는 산세리프 폰트 사용)
*   **Headline (H1):** Pretendard Bold, 48pt. (최대 2줄 제한. 메시지 전달에 집중)
*   **Sub-Headline (H2):** Pretendard SemiBold, 32pt. (핵심 기능을 요약할 때 사용)
*   **Body Text:** Pretendard Regular, 16pt. (간결하고 명료한 문장 구성에 최적화)
*   **CTA Button:** Pretendard Medium, 16pt. (단순하고 직접적인 명령형 문구 사용)

### 1.3. 아이콘 및 이미지 스타일 (Iconography & Imagery)
*   **아이콘:** Line-based (선형) 및 Minimalist (최소주의) 스타일. 복잡한 디테일이나 그라데이션 사용 금지.
*   **이미지:** 기능 작동 방식의 **스크린샷 또는 단순 도식화**를 최우선으로 사용. (추상적인 개념 사진 지양).
*   **톤앤매너:** 진중함, 실용성, 군더더기 없음.

## 🖥️ 2. UI/UX 구조 및 컴포넌트 사양 (Responsive Landing Page)
**구조:** 검증된 6-섹션 구조를 기반으로, '가치 제시 -> 문제 정의 -> 해결책 제시 -> 작동 방식 시연 -> CTA -> 안정성 강조'의 흐름을 유지합니다.

| 섹션 ID | 섹션명 | 핵심 기능 및 레이아웃 | 디자인 사양 (간단함/효율성 강조) |
| :--- | :--- | :--- | :--- |
| **S1** | **Hero Section (최상단)** | H1 (핵심 가치) + Sub-Headline (문제 정의) + **단일 CTA 버튼** | **핵심 집중.** 중앙 정렬. H1은 최대 2줄로 압축. CTA 버튼은 `Primary Color`를 사용하고, '지금 시작'처럼 직관적인 명령형 문구 사용. |
| **S2** | **Problem/Pain Point** | 타깃의 고통(Pain Point)을 2~3가지 간결한 항목으로 제시. | **최소화.** 불릿 포인트나 작은 아이콘과 함께 1~2줄의 문장으로 구성. 감정적 호소보다는 '현실적 불편함'을 언급. |
| **S3** | **Solution/Feature** | MVP의 핵심 기능 3가지 제시. | **간결한 격자 레이아웃.** 3-Column Grid 사용 (Desktop). 각 기능은 `Minimalist Icon` + `H3 (기능명)` + `Body Text (1줄 요약)`으로 구성. |
| **S4** | **How It Works (작동 방식)** | 도구 사용 과정을 3단계(Step 1 -> Step 2 -> Step 3)로 시각화. | **흐름 강조.** 시간 순서에 따라 좌->우 또는 상->하로 흐름을 명확히 제시. 각 단계는 단순화된 인포그래픽(화살표, 단순 박스)으로 표현. |
| **S5** | **Trust & Proof** | 사용 후기 또는 안정성 강조 (PayPal 연동 강조). | **진중함 확보.** 가짜 후기 대신, "수많은 사용자가 경험한 안정적인 자동화" 등 시스템의 신뢰성에 초점. (작은 `Accent Teal` 체크 마크 사용) |
| **S6** | **Final CTA & Pricing** | 최종 결제 유도 및 Pricing Table 제시. | **단일 목적.** Pricing은 복잡한 기능 대신 '가치'에 기반하여 단순화. CTA 버튼은 S1과 동일한 `Primary Color` 및 문구로 통일하여 일관성 유지. |
